# Installera Charlottendal TKL

Den fullständiga, aktuella installationsguiden finns i **[README: Installera CDA-TKL](../README.md)**.

Där finns alla steg för Raspberry Pi 5, Mac och Windows: förberedelser, SSH-inloggning, installation,
första start, TrainMeet, uppdatering från det tidigare installationsförrådet och felsökning.

Installation och uppdatering hämtar nu programmet direkt från det publika förrådet
[beahead-ab/cda-tkl](https://github.com/beahead-ab/cda-tkl). Det behövs inget separat installationsförråd.

Fördjupning: [Pi, nätverk och säkerhetskopiering](raspberry-pi.md),
[användare](anvandare.md) och [LocoNet](loconet-anslutning.md).
